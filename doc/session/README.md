# Session export

Captured from the first Grok session that created this repo.

| File | Contents |
|------|----------|
| `chat.md` | Human-readable user/assistant conversation |
| `chat.jsonl` | Same turns as JSONL (`role`, `text`) |
| `session-meta.json` | Session id, model, turn counts |

System prompts, tool traces, and other Grok sessions on the first machine are **not** included.

For decisions and next steps see `../../AGENTS.md` and `../handoff/2026-08-14-knowledge.md`.
